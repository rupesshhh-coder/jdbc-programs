# 🔗 JDBC Programs

A collection of **Java JDBC programs** created to practice database connectivity, SQL operations, CRUD operations, and different JDBC concepts.

---

## ✨ Programs Included

* 🔌 Test MySQL Database Connection
* ➕ Insert Data using JDBC
* ➕ Insert Data using `PreparedStatement`
* 📋 Insert Multiple Records using `PreparedStatement`
* 🔍 Select Data
* 📝 Select Data and Convert to String
* ✏️ Update Data
* ❌ Delete Data
* 👨‍🎓 Student Model using Java

## ▶️ How to Run

1. Clone or download the repository.
2. Open the project in **Eclipse IDE**.
3. Add the required **MySQL JDBC Driver** to the project.
4. Configure your MySQL database connection in the required Java class.
5. Run the individual Java programs.
6. Check the results in the console and database.

---

## 📚 Purpose

This project was created to understand and practice **Java Database Connectivity (JDBC)** and learn how Java applications communicate with a MySQL database.
